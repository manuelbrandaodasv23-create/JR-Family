# JR Family — Android de teste

Aplicativo com compartilhamento autorizado e visível de localização.

Este repositório contém somente os arquivos necessários para compilar o Android. O backend e os backups permanecem no pacote original.

O workflow APK Android de teste gera JR-Family-teste.apk com assinatura de desenvolvimento. Sem configurar JR_API_BASE_URL com a URL do servidor e o Firebase, login, sincronização de localização e notificações não estão operacionais. Não foi validado em aparelho físico.
